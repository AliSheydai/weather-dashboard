# Plan: Dynamic Weather Background for TemperatureCard

## Overview
Add a dynamic background image to the main temperature card that changes based on current weather condition and time of day (day/sunset/night).

## Files to Change

| File | Action |
|------|--------|
| `src/lib/weatherBackground.ts` | **Create** — helper function |
| `src/components/weather/TemperatureCard.tsx` | **Edit** — add background layer |
| `src/app/home-client.tsx` | **Edit** — pass new props |

## Step 1: Create `src/lib/weatherBackground.ts`

New utility module with:

- **`parseTimeToToday(timeStr: string): Date`** — parses locale time strings like `"6:30:00 AM"` into a Date object set to today. Handles AM/PM and 24h format. Returns epoch as fallback on invalid input.
- **`getTimeOfDay(sunrise, sunset): { isDay, isSunset }`** — compares current time against sunrise/sunset. Sunset window = 30 minutes before sunset.
- **`normalizeCondition(condition: string): string`** — maps OWM condition strings (`"Clear"`, `"Rain"`, `"Drizzle"`, `"Snow"`, `"Clouds"`, etc.) to a normalized key. Fallback = `"clouds"`.
- **`getWeatherBackground(condition, sunrise, sunset): { image, isDay, isSunset }`** — main exported function.

Background mapping table:

| Key | Day | Night | Sunset |
|-----|-----|-------|--------|
| clear | `/weather/sun.jpg` | `/weather/night-clouds.jpg` | `/weather/Sunset.jpg` |
| clouds | `/weather/day-clouds.jpg` | `/weather/night-clouds.jpg` | — |
| rain | `/weather/rany-day.jpg` | `/weather/rany-night.jpg` | — |
| drizzle | `/weather/rany-day.jpg` | `/weather/rany-night.jpg` | — |
| snow | `/weather/snow-day.jpg` | `/weather/snow-night.jpg` | — |
| thunder | `/weather/rany-day.jpg` | `/weather/rany-night.jpg` | — |

Unknown conditions fall back to `clouds`.

## Step 2: Update `TemperatureCard.tsx`

1. Add `sunrise: string` and `sunset: string` to `TemperatureCardProps`
2. Import `getWeatherBackground` from `@/lib/weatherBackground`
3. Add `useMemo` to compute the background result
4. Replace the root `<div>` gradient with a layered structure:
   - **Image layer**: `<div>` with `absolute inset-0 bg-cover bg-center`, `style={{ backgroundImage: ... }}`
   - **Overlay layer**: `<div>` with `absolute inset-0`, using `bg-black/25` (day) or `bg-black/45` (night) for text readability
   - **Content layer**: existing flex column (unchanged)
5. Add `transition-opacity duration-300` to the overlay for smooth background change transitions
6. Preload the current background image via `useEffect` + `new Image()`

## Step 3: Update `home-client.tsx`

Pass the new props to `<TemperatureCard>`:
```
sunrise={weather.sunrise}
sunset={weather.sunset}
```

These values are already available from the Zustand store — no store changes needed.

5. Check that all text (temperature, description, feels like, H/L) remains readable against the background
