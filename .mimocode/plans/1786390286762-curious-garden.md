# Responsive UI/UX Audit & Fix Plan

## Overview

Full responsive audit of the Weather Dashboard. The desktop design is preserved — only responsive behavior is fixed. The project uses **Tailwind CSS v4** with CSS-first config, **Next.js 16**, **shadcn/ui**, and **framer-motion**.

## Breakpoint Strategy

| Breakpoint | Width | Role |
|---|---|---|
| Default | < 640px | Mobile (primary target for fixes) |
| `sm:` | 640px+ | Large mobile / small tablet |
| `md:` | 768px+ | Tablet |
| `lg:` | 1024px+ | Laptop / Desktop |

---

## Step 1: Layout Shell — DashboardLayout sidebar gap fix

**File:** `src/components/layout/DashboardLayout.tsx`

**Problem:** Sidebar uses `hidden lg:flex` (visible at 1024px+), but `useIsMobile()` returns `true` only below 768px. Between 768px–1024px, the sidebar is hidden AND no hamburger menu appears. Users in this range lose sidebar access entirely.

**Fix:** Change the desktop sidebar visibility from `hidden lg:flex` to `hidden md:flex` so the sidebar appears at 768px+. The mobile overlay (Sheet) already handles < 768px via `useIsMobile()`. This closes the 768px–1024px gap.

```tsx
// Before
<aside className="hidden lg:flex flex-col shrink-0">

// After
<aside className="hidden md:flex flex-col shrink-0">
```

**Verify:** Sidebar visible at 768px+, Sheet overlay below 768px, no gap.

---

## Step 2: Main Content Area — home-client.tsx two-column breakpoint

**File:** `src/app/home-client.tsx`

**Problem:** Two-column layout switches at `lg:` (1024px). Between 768px–1024px, users see a single-column stacked layout. The left column has `lg:w-[38%]` and right column has `lg:flex-1`. These should activate at `md:` to match the sidebar fix.

**Fix:** Change `lg:` prefixes to `md:` for the two-column layout:

```tsx
// Before
<div className="h-full flex flex-col lg:flex-row gap-3 animate-fade-in overflow-auto lg:overflow-hidden">
  <div className="lg:w-[38%] flex flex-col gap-3 lg:min-h-0">
  <div className="lg:flex-1 min-h-0">

// After
<div className="h-full flex flex-col md:flex-row gap-3 animate-fade-in overflow-auto md:overflow-hidden">
  <div className="md:w-[38%] flex flex-col gap-3 md:min-h-0">
  <div className="md:flex-1 min-h-0">
```

Also update `lg:flex-[1]`, `lg:flex-[2]`, `lg:min-h-0` to `md:` equivalents in the same file.

**Verify:** Two-column layout appears at 768px+ alongside sidebar.

## Step 3: CurrentWeather.tsx — Responsive text and icons

**File:** `src/components/weather/CurrentWeather.tsx`

**Problems:**
- `text-8xl` (96px) overflows on mobile
- `h-24 w-24` icons too large on mobile
- `p-8` padding too large on mobile

**Fixes:**

```tsx
// Icon: before
<Sun className="h-24 w-24 text-yellow-400" />
// Icon: after
<Sun className="h-16 w-16 sm:h-20 sm:w-20 lg:h-24 lg:w-24 text-yellow-400" />
// (Apply same pattern to all 5 icon variants)

// Temperature: before
<div className="text-8xl font-bold text-white tracking-tighter">
// Temperature: after
<div className="text-5xl sm:text-6xl md:text-7xl lg:text-8xl font-bold text-white tracking-tighter">

// Padding: before
<div className="... p-8">
// Padding: after
<div className="... p-4 sm:p-6 lg:p-8">
```

**Verify:** Temperature and icons scale down gracefully on 320px screens.

## Step 4: HourlyForecast.tsx — Responsive grid

**File:** `src/components/weather/HourlyForecast.tsx`

**Problem:** `grid-cols-6` with no responsive variant. 6 items in a row on mobile is unreadable.

**Fix:**

```tsx
// Before
<div className="grid grid-cols-6 gap-3">

// After
<div className="grid grid-cols-3 sm:grid-cols-6 gap-2 sm:gap-3">
```

**Verify:** 3 columns on mobile, 6 on sm+. No overflow.

## Step 6: Modal Headers — flex-wrap for overflow safety (8 files)

**Files:** All modal components with `flex items-center gap-4` headers:
- `AirQualityModal.tsx` (line 213)

- `UVIndexModal.tsx` (line 199)
- `VisibilityModal.tsx` (line 187)
- `WindModal.tsx` (line 182)

**Fix:** Add `flex-wrap` to prevent overflow on narrow dialog widths:

```tsx
// Before

// After

```

**Verify:** Large values + badges wrap correctly on narrow screens.

## Step 7: VisibilityModal.tsx + WindModal.tsx — Side-by-side charts stacking

**Files:**
- `VisibilityModal.tsx` (line 216): `grid grid-cols-2 gap-3`
- `WindModal.tsx` (line 284): `grid grid-cols-2 gap-3`

**Fix:** Stack charts on mobile:

```tsx
// Before
<div className="grid grid-cols-2 gap-3">

// After
<div className="grid grid-cols-1 sm:grid-cols-2 gap-3">
```

**Verify:** Charts stack vertically on mobile, side-by-side on sm+.

## Step 8: NotificationBell.tsx — Dropdown width safety

**File:** `src/components/header/NotificationBell.tsx` (line 293)

**Problem:** `fixed w-80` (320px) dropdown can overflow on screens < 320px or go off-screen.

**Fix:**

```tsx
// Before
className="fixed w-80 bg-[#09090d] ..."

// After
className="fixed w-[calc(100vw-2rem)] max-w-80 sm:w-80 bg-[#09090d] ..."
```

**Verify:** Dropdown respects viewport width on all screen sizes.

## Step 9: Gauge ResponsiveContainers — Percentage widths

**Files:**
- `AirQualityModal.tsx` (line 246): `ResponsiveContainer width={280} height={150}`
- `VisibilityModal.tsx` (line 224): `ResponsiveContainer width={200} height={130}`

**Fix:** Use percentage-based widths:

```tsx
// AirQualityModal: before
<ResponsiveContainer width={280} height={150}>
// AirQualityModal: after
<ResponsiveContainer width="100%" height={150}>

// VisibilityModal: before
<ResponsiveContainer width={200} height={130}>
// VisibilityModal: after
<ResponsiveContainer width="100%" height={130}>
```

Also remove the `max-w-[280px]` constraint in `UVIndexModal.tsx` (line 233) if present.

**Verify:** Gauges scale with container width.

## Step 10: DailyForecast.tsx — Tighter fixed widths on mobile

**File:** `src/components/weather/DailyForecast.tsx`

**Problem:** Fixed `w-16`, `w-12`, `w-8` columns leave only ~88px for the temperature bar on 320px screens.

**Fix:** Use responsive widths:

```tsx
// Before
<div className="w-16 text-sm font-medium ...">     // Day name
<div className="w-8 flex justify-center">            // Icon
<div className="w-12 text-right text-sm ...">        // Min temp
<div className="w-12 text-right text-sm ...">        // Max temp

// After
<div className="w-12 sm:w-16 text-xs sm:text-sm font-medium ...">
<div className="w-6 sm:w-8 flex justify-center">
<div className="w-10 sm:w-12 text-right text-xs sm:text-sm ...">
<div className="w-10 sm:w-12 text-right text-xs sm:text-sm ...">
```

**Verify:** Temperature bar has adequate space on 320px screens.

---

## Step 11: MetricDetailDialog.tsx — Mobile-safe padding

**File:** `src/components/weather/MetricDetailDialog.tsx`

**Problem:** Fixed `p-6` padding in the dialog header and content areas. On mobile, the dialog fills the screen and 24px padding on each side consumes 48px.

**Fix:**

```tsx
// Before
<div className="p-6 pb-0">
<div className="p-6 pt-4 max-h-[75vh] ...">

// After
<div className="p-4 sm:p-6 pb-0">
<div className="p-4 sm:p-6 pt-4 max-h-[75vh] ...">
```

**Verify:** Dialog content has more room on mobile screens.

---

## Step 12: Final Verification

After all changes:
1. Run `npm run build` to verify no TypeScript/build errors
2. Manually test at these widths: 320px, 375px, 640px, 768px, 1024px, 1440px
3. Check for: no horizontal scroll, no overlapping, no text clipping, no broken grids
4. Verify all modals open and display correctly at each breakpoint
5. Verify sidebar toggle works at all sizes
