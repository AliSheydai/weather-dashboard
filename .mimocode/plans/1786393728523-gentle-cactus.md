# Plan: Add Mini Gauge Chart to UV Index Card

## Goal
Replace the thin gradient progress bar in the UV Index `MetricCard` with a miniature semi-circle gauge that mirrors the one in the `UVIndexModal`, making the card more visually rich.

## Files to Change

| File | Action |
|------|--------|
| `src/components/weather/MiniUVGauge.tsx` | **Create** — new mini gauge component |
| `src/components/weather/MetricsGrid.tsx` | **Edit** — swap `extra` content + import + remove unused `uvPct` |

## Step 1: Create `MiniUVGauge.tsx`

A self-contained component using the same Recharts `PieChart` pattern as the modal gauge, scaled to 140x75px:

- **12 colored `<Pie>` segments** for zone backgrounds (green/yellow/orange/red/purple) — same `GAUGE_COLORS` as the modal
- **1 filled `<Pie>`** for the current UV arc (value/12)
- **Simplified `<GaugeNeedle>`** SVG — white needle with colored tip, same rotation logic as modal
- **No labels** (0,3,6,9,12) — too small; the UV value is already displayed above
- **No `ResponsiveContainer`** — fixed `PieChart width={140} height={75}` since the card width is predictable

Dimensions (scaled ~50% from modal):

| Prop | Modal | Mini |
|------|-------|------|
| Width | 280px | 140px |
| Height | 160px | 75px |
| outerRadius (bg) | 110 | 50 |
| innerRadius (bg) | 80 | 36 |
| outerRadius (fill) | 108 | 48 |
| innerRadius (fill) | 82 | 38 |

## Step 2: Edit `MetricsGrid.tsx`

1. **Add import**: `import { MiniUVGauge } from "./MiniUVGauge";`
2. **Replace UV card `extra`** (lines 93-99): swap the progress bar `<div>` with `<MiniUVGauge uvIndex={uvIndex} />`
3. **Remove `uvPct`** (line 81): no longer needed since the gauge computes internally

## Why Replace (Not Add Alongside)
The gauge already encodes the same gradient concept via its colored segments. Keeping both the bar and gauge would clutter the compact card.
